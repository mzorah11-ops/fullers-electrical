# Fuller's Electrical Services Ltd: landing page

Static site (no build step). Open `index.html`, or publish with GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / root).

- Contact details, hours and MyBuilder link: the `SETTINGS` block near the end of `index.html`
- Reviews: `reviews.json` (format in `reviews.template.json`)
- Photos: put files in `images/` and list them in the `PHOTOS` array in `index.html`
- Remove the `noindex` meta tag in `index.html` when the site is ready to be found on search engines
